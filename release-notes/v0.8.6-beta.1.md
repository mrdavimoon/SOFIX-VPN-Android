# SOFIX VPN Android 0.8.6 Beta 1 — локальная маршрутизация Hybrid B

22 ноября 2026 года.

## Изменения для пользователя

- Android SMART повторяет опубликованный профиль Happ Hybrid B: российские и другие неограниченные адреса открываются напрямую **с IP самого телефона**, без прохода через Москву.
- В SOFIX VPN идут только домены и IP-подсети ресурсов из списка ограничений. Для Telegram/Instagram есть маршруты по IP, а для остальных по доменным именам.
- Локальная маршрутизация включается только в режиме SMART. Режим «Весь интернет через VPN» и собственные исключения продолжают работать отдельно, как и прежде.
- Настройки Android и Xray позволяют определить домен по HTTP/TLS SNI, когда приложение уже разрешило адрес в IP. Система использует IPIfNonMatch для маршрутизации по подсетям.
- Оставлены серверные четыре московских входа в подписке. Новый клиент предпочитает Москва-1 TCP, затем Москва-2 TCP. При обновлении подписки сохраняется пользовательский выбор работающего профиля.
- Списки доменов, подсетей и российских исключений собраны из действующего Happ Hybrid B; обновления проходят по подписанному манифесту Ed25519. Без сети используется встроенный последний известный список.
- Исправлены надписи в разделе раздельного туннелирования.

## Совместимость и предосторожности

- Тот же package ID com.sofix.vpn, более высокий versionCode 764 и прежний ключ подписи выпуска — установка поверх 0.8.5 без очистки данных.
- Никаких изменений серверов, Marzban, начислений, Telegram-привязок, тарифов и UUID.
- Ручные правила пользователя имеют приоритет, прежние экспертные настройки остаются с возможностью отката.
- Данные о маршрутах берутся из канонической политики Happ. Генератор манифеста не публикует подписки, токены, персональные данные или приватные ключи.
- Подписной манифест версии 3 должен быть размещён в публичном GitHub-репозитории; если он пока не опубликован, новая версия использует встроенную копию этой политики.
- IP-адреса московских узлов могут меняться: для актуализации списков нужен новый подписанный манифест при смене IP. Это не требует новой версии APK.

## Что проверить на физическом Android

1. Обновление с подписанной 0.8.5 без удаления данных, повторной привязки или повторной оплаты.
2. Проверка внешнего IP для sberbank.ru, gosuslugi.ru, yandex.ru — должен быть IP телефона, а не московской VPS.
3. Проверка YouTube, Telegram, Instagram, ChatGPT — должны открываться через VPN; для ресурсов с DNS/IPv6/QUIC дополнительно измерить реальный маршрут.
4. Проверка Москва-1/Москва-2 TCP, выбор UDP в приложении если клиентский движок поддерживает соответствующий протокол.
5. Переключение на «Весь интернет через VPN», ручной direct/proxy список, обновление подписки и работа при отсутствии связи с сервером.
6. Тесты DNS и IPv6 leaks, Android Always-on VPN, LTE/5G и Wi-Fi с разных операторов.

Обновление ещё нельзя считать проверенным на реальном телефоне только по исходникам и автотестам.
