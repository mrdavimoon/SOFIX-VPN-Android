# SOFIX VPN Android 0.4.0 Beta 1

**Встроенное обновление и постоянная подпись приложения · 20 октября 2026**

### Добавлено
- Кнопка **«Проверить обновления»** на главном экране.
- Поиск новых версий SOFIX VPN среди официальных GitHub Releases.
- Экран «Обновления»: текущая версия, доступная версия и список изменений.
- Загрузка APK непосредственно в приложение с показом прогресса.
- Проверка размера и SHA-256 скачанного APK, а также соответствия пакета и более нового номера версии.
- Запуск стандартного системного установщика Android после подтверждения пользователя.

### Безопасность и совместимость
- С этой версии APK подписывается **постоянным ключом SOFIX**, а не случайным ключом GitHub Actions.
- Подпись APK Android проверяет при установке. Следующие версии, подписанные тем же ключом, смогут обновляться поверх 0.4 без потери привязки и настроек.
- Приложение не получает и не запрашивает ключи подписи. Секреты остаются вне публичного репозитория.
- Для установки Android может попросить разрешить обновления из SOFIX VPN; пользователь подтверждает действие в системном окне.

### Важно перед установкой
- **Переход с 0.1/0.2/0.3 на 0.4 — один раз через переустановку**: предыдущие APK подписаны другим временным ключом. Android не разрешит бесшовное обновление поверх них.
- Чтобы не потерять устройство в списке трёх подключений, отвяжите старое устройство в Mini App перед удалением прежнего приложения. Затем установите 0.4 и привяжите телефон снова.
- Начиная с 0.4, обновления по кнопке будут работать поверх установленной версии, если не менять стабильную подпись.

### Известные ограничения
- Скачивается **полный APK**, а не разница между версиями.
- Система Android требует подтверждения установки; без root/MDM тихая установка недоступна.
- Функцию загрузки и установки нужно подтвердить на реальном Android-телефоне; автоматизированная сборка не проверяет пользовательский сценарий установки.
- Основной VPN и управление аккаунтом через Mini App не изменены.
