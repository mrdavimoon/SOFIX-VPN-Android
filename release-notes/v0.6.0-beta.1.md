# SOFIX VPN Android 0.6.0 Beta 1

**Автозапуск VPN после перезагрузки · 20 октября 2026**

### Добавлено
- На главном экране появился переключатель **«Автозапуск VPN — После включения телефона»**.
- Переключатель управляет реальным системным механизмом приложения (настройка v2rayNG Start on Boot), который запускает VPN после получения Android-события загрузки.
- Кнопка **«Постоянная VPN в Android»** открывает системные VPN-настройки. На OPPO/ColorOS там можно отдельно включить «Постоянная VPN» для более надёжного восстановления подключения.
- Настройка автозапуска сохраняется после выхода из приложения и следующих обновлений APK.

### Исправлено
- Ранее Android-разрешение ColorOS «Автоматический запуск» не включало внутренний параметр VPN-клиента, который по умолчанию оставался выключенным. Теперь он доступен на главном экране SOFIX.
- После истечения анонимного пробного периода (15 минут) приложение **не запускает просроченный пробный VPN автоматически** при перезагрузке.
- Старые активные аккаунты и платные подписки продолжают использовать прежний VPN-движок Xray без изменения ключей.

### Как проверить на OPPO A54 5G
1. Обновиться с версии 0.5 через кнопку приложения. Подпись APK не менялась.
2. Открыть SOFIX VPN и включить «Автозапуск VPN».
3. Оставить VPN подключённым, перезагрузить телефон, дождаться разблокировки, появления Wi-Fi и восстановления VPN.
4. Если ColorOS ограничит автозапуск, открыть системные настройки через кнопку «Постоянная VPN в Android» и включить постоянную VPN (необязательно включать «Блокировать подключения без VPN»).
5. Проверить, что интернет действительно проходит через VPN — один только значок в строке состояния ещё не доказывает доступность интернета.

### Ограничения
- Некоторые прошивки ColorOS могут блокировать запуск после перезагрузки, несмотря на разрешение автозапуска. Для таких устройств предпочтителен системный режим «Постоянная VPN».
- После подключения пробного доступа нельзя автоматически запускать его после истечения срока, даже если пользователь включил переключатель.
- Системная «Блокировка подключений без VPN» не включается автоматически, чтобы не оставить телефон без интернета при окончании подписки.
- Работа после реальной перезагрузки на ColorOS 13 требует проверки на физическом OPPO.

### Безопасность и исходники
APK подписывается постоянным ключом SOFIX, как версии 0.4–0.5. Обновление должно сохранять данные приложения и подписку. Модификации v2rayNG/Xray распространяются по GPLv3; архив исходного кода и SHA-256 прилагаются.
