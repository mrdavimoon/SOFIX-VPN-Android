# SOFIX VPN Android 0.8.0 Beta 1

**Раздельное туннелирование, диагностика, остаток подписки, обновляемые правила и демо первого запуска**

## Добавлено
- Настройки → Раздельное туннелирование: **Умный**, **Весь интернет через VPN**, **Только выбранные сайты**.
- Списки **«Всегда через VPN»** и **«Всегда напрямую»**, изменение домена, контроль конфликтов и приоритет более точного домена.
- Встроенная проверка «Как откроется сайт?» показывает принятое правило без передачи адреса на сервер.
- Российские зоны `.ru` и `.рф`, геокатегория RU и проверяемые серверные исключения; неизвестные публичные ресурсы по умолчанию через VPN.
- Обновляемые отдельно от APK правила доменов с подписью Ed25519, защитой от подмены и локальным последним рабочим пакетом.
- Состояния соединения: нет сети, подключаем, защита подтверждена, соединение не подтверждено. Диагностика сравнивает контрольный внешний IP с выходом без VPN.
- Остаток подписки на главном экране, из авторизованного API устройства, и переход в Mini App.
- Скрытая демонстрация первого запуска: 7 нажатий на номер версии в настройках. Демонстрация локальна, не делает платежей, не выдаёт пробные ключи и не трогает реальные устройства.

## Исправлено и сохранено
- VPN не должен показывать «Защита активна» только из-за наличия системного значка VPN, если не удалось подтвердить прокси-маршрут.
- Старые настройки и привязка сохраняются при обновлении с 0.7.
- Автоматический запуск после перезагрузки, Telegram и обновления APK не менялись.

## Известные ограничения
- При изменении маршрутизации требуется переподключить VPN из интерфейса.
- При наличии существующих экспертных правил v2rayNG новый набор не применяется автоматически без явного согласования миграции, чтобы избежать потери настроек.
- Доменные правила не охватывают все DNS-over-HTTPS/ECH/IP-only приложения. Неизвестный трафик идёт по режиму по умолчанию.
- Криптографическая проверка Ed25519 зависит от Android security provider; если алгоритм недоступен, новый сетевой пакет отклоняется, используется безопасный встроенный/ранее проверенный набор.
- Без физического теста нельзя утверждать, что диагностика и маршрутизация работают одинаково на каждой прошивке.
- Для полноценного теста создания нового аккаунта нужен отдельный Telegram-профиль; локальная демонстрация не создаёт аккаунт.

## Проверка на OPPO A54 5G
1. Обновить 0.7 → 0.8 поверх установленной версии. Проверить, что VPN и авторизация сохранились.
2. В настройках открыть маршрутизацию, убедиться, что выбран «Умный».
3. Проверить доступ к российским сайтам и сервисам через VPN, затем добавить исключения и переподключиться.
4. Выключить Wi-Fi: приложение должно написать, что ждёт интернет, хотя значок VPN может остаться.
5. После возврата Wi-Fi проверить реальную диагностику.
6. Проверить остаток подписки, а также демо первого запуска, не сбрасывая аккаунт.
7. Проверить автозапуск после перезагрузки и автообновление на следующую версию.

## Безопасность
- Личные списки не покидают телефон; в отчёт диагностики не попадают VPN-ключи, URL подписки и историю сайтов.
- Пакеты правил ограничены по размеру и проходят проверку подписи; скачать неподписанный список нельзя.
- APK с постоянной подписью SOFIX, исходники модифицированного v2rayNG/Xray под GPLv3 и SHA-256 прилагаются.

_Это описание для релиза-кандидата. Фактическая публикация допускается только после успешных тестов, сборки и подписи APK._
