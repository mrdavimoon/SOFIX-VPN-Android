# SOFIX VPN Android 0.8.3 Beta — восстановление оплаченного телефона

22 октября 2026. Исправление по результатам проверки реального оплаченного HONOR.

## Что произошло

У клиентки оплаченный основной VPN-профиль остаётся действующим, но все прежние привязки Android имеют статус `revoked` в базе SOFIX. Версии 0.8.1–0.8.2 могли восстановить конфигурацию только по **действующему** сохранённому токену. Отозванный токен правильно отклоняется сервером (HTTP 401), поэтому прежнее исправление не помогает.

Перевыдавать старый отозванный ключ автоматически **нельзя**.

## Новый сценарий Android

1. При HTTP 401/403 от `GET /mobile/api/me` Android показывает: «Телефон отвязан. Восстановите доступ через Telegram», не маскируя проблему текстом «Нет подписки».
2. Нажатие **«Восстановить подписку»** или **«У меня уже есть подписка»** создаёт только *временный запрос привязки* через `POST /mobile/api/pair/start`. Это не новая подписка, не платёж и не бесплатный пробник.
3. Приложение показывает шестизначный код и открывает Telegram Mini App через подписанный challenge.
4. Клиент подтверждает свой телефон в Telegram (Telegram HMAC, challenge, код, ограничение трёх устройств); сервер допускает только владельца действующей платной подписки.
5. По возвращении Android проверяет статус созданного токена через `GET /mobile/api/me`.
6. Только после состояния `ready` получает собственную VPN-подписку нового устройства, импортирует профиль в Xray/v2rayNG, **выбирает именно новый сервер** и только тогда заменяет старый локальный токен.
7. Если запрос истёк, можно создать новый. Временный сбой интернета ничего не стирает. Повторная оплата не нужна.

## Дополнительно исправлено

- Платное устройство имеет приоритет перед старым пробным токеном. Сохранившийся пробник не должен заслонять оплаченный профиль.
- Периодический статус на главном экране не переписывает сообщение об отозванной привязке устаревшим кешем подписки.
- Существующая работа пробника 15 минут, маршрутизация, автообновление и серверное управление устройствами не изменены.
- Отозванные устройства остаются отозванными; новый ключ может быть создан только через подтверждённый Telegram.

## Инструкция клиенту

**Не удалять приложение и не очищать его данные.** Обновить установленную версию поверх старой. Открыть SOFIX VPN → **«Восстановить подписку»** (или «У меня уже есть подписка») → запомнить шестизначный код → **«Открыть Telegram»** → подтвердить привязку кодом → вернуться в SOFIX VPN. Убедиться, что отображается оставшийся оплаченный срок, затем подключить VPN.

## Проверка

Автоматические тесты и сборка подтверждают программную совместимость, но E2E привязку должен завершить сам владелец Telegram-аккаунта на своём HONOR. Статус первой успешной привязки и нового ключа необходимо проверить после действия клиента.

Изменения не затрагивают кошелёк, срок подписки, платежи и Device Guard.
