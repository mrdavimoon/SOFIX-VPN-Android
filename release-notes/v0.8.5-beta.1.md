# SOFIX VPN Android 0.8.5 Beta — актуальная маршрутизация и SMART Москва

4 ноября 2026.

## Для пользователя

- Новый оплаченный Android-телефон при первой привязке предпочитает «Москва SMART | TCP». Если этот профиль отсутствует, приложение безопасно выбирает другой доступный TCP-сервер.
- Приложение всегда обновляет список серверов при проверке подтверждённой подписки устройства. Изменения IP и состава серверов доступны без переустановки APK.
- Если клиент выбрал действующий сервер вручную, новая проверка подписки его не переключает.
- При кратковременном сбое обновления приложение сохраняет прежний локальный профиль, не теряя доступ к уже оплаченной подписке.
- Базовый список сайтов для умной маршрутизации расширен: Telegram, YouTube, Instagram, WhatsApp, TikTok, Discord, Claude и сопутствующие домены. Российские сайты по-прежнему идут напрямую, а пользовательские исключения имеют приоритет.
- Списки обновляются отдельно от APK по подписанному Ed25519-манифесту. Клиент проверяет подпись, срок годности и версию; недоверенные данные не применяются.

## Совместимость и безопасность

- Подключение Москва SMART TCP (VLESS/REALITY) выбирается первым; UDP/Hysteria2 остаётся для клиентов, которые поддерживают его, и не выбирается новым Android-приложением по умолчанию.
- Существующие привязки, токены, оплаченные дни и подписки не пересоздаются.
- Запрос через Telegram Mini App и подтверждение без шестизначного PIN сохраняются.
- Независимые ключи каждого устройства остаются привязаны к основному платному аккаунту.
- Сроки истечения подписки проверяются на сервере. Отозванные токены не активируются повторно.
- Сохраняются режимы VPN, ручные правила и возможность вернуться к прежней экспертной маршрутизации.
- Подпись APK выполняется старым постоянным ключом SOFIX, без передачи ключа на GitHub Actions.

## Что протестировать на Android

1. Обновление поверх 0.8.4 без удаления данных, Telegram-авторизации и повторной оплаты.
2. Первый запуск и выбор Москва SMART TCP после подтверждения устройства.
3. Открытие Telegram, YouTube и Instagram, затем российского сайта без VPN.
4. Ручной выбор другого сервера и возврат в приложение без незапрошенного переключения.
5. Потеря интернета во время обновления списка, повторное подключение и автоматическое получение изменений.
6. Работа после перезагрузки телефона и проверка системной постоянной VPN.
